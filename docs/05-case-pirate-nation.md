# 05 · Case Study — Pirate Nation

**Scale:** 207 accounts · **Result:** ≈ ¥600K realized · **Period:** 2024

## Setup

A fully on-chain pirate game with a real in-game economy and a token-linked reward structure — the kind of campaign where operations quality, not luck, decides the outcome. The matrix was built in cohorts, each with progression roles and market roles (doc 01).

## What decided it

- **Economy first, rewards second.** Accounts were run as businesses inside the game's economy — producing, trading, and progressing — so value accumulated in assets the market actually wanted, not only in speculative reward points.
- **Wave discipline.** Cohorts entered in waves; when the meta shifted mid-campaign, later waves adopted the new playbook without stranding the earlier ones.
- **Settled-profit accounting.** Proceeds were consolidated and realized continuously (doc 02, stage 5), so the final number was money already secured, not a balance screenshot.

## Lessons carried forward

1. In a real game economy, the operator who understands item markets beats the operator who only farms tasks.
2. Cohort waves are cheap insurance against mid-campaign rule changes.
3. The ledger (doc 04) is what turned "we did well" into a number that could be verified, repeated, and improved.
