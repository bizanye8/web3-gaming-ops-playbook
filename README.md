## Operating principles

- **Settled profit is the only scoreboard.** Unrealized balances are weather, not results.
- **Every account is a cost center and a profit center.** Track both, per account, from day one.
- **The exit is designed before the entry.** Campaigns end on rules, not on moods.
- **Operations beat predictions.** Process quality compounds; market timing doesn't.
